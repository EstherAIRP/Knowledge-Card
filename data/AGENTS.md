# AGENTS.md — Generated data

This directory contains machine-generated, disposable indexes.

## `relations.json`

- Generated by `npm run relations:build`.
- Must not become the source of truth for Knowledge Card metadata.
- Do not hand-edit generated edges to express user intent.
- Human relation decisions belong in `config/relation-overrides.yaml`.
- Regeneration must be deterministic with respect to effective Card metadata, overrides, and generator code; avoid timestamp-only rewrites when inputs are unchanged.
- Before committing a relation index change, run `npm run relations:validate` and `npm test`.
